# OverTheWire Write-ups

Este repositorio documenta mi progreso en los laboratorios de **OverTheWire**, una plataforma diseñada para aprender conceptos de Linux, seguridad ofensiva y explotación de vulnerabilidades mediante retos prácticos.

## Objetivos

* Fortalecer conocimientos de Linux.
* Mejorar habilidades de enumeración.
* Practicar técnicas de explotación.
* Documentar el proceso de resolución de cada reto.
* Construir un portafolio técnico.
